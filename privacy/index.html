本ポリシーは、Claude Code先生（以下「当方」）が提供する SNS 自動運用システム「Claude Code Sensei SNS Hub」（以下「本サービス」）の利用に関して、利用者から取得する情報、その利用目的、第三者への開示、および利用者の権利について定めるものです。

1. 取得する情報

本サービスは、Meta Platforms（Facebook / Instagram）の Graph API および X (Twitter) API を利用し、当方が運営するアカウントの管理・投稿配信を行います。本サービスは、第三者の個人情報を取得・保存することはありません。

  • 当方所有の Facebook ページ・Instagram アカウント・X アカウントのアクセストークン（macOS Keychain にローカル保管）
  • 当方が生成・投稿したコンテンツのテキスト、画像、動画
  • 投稿後の公開エンゲージメント指標（いいね数、リーチ数、インプレッション数等の集計値のみ）

2. 情報の利用目的

  • 当方所有の SNS アカウントへのコンテンツ自動投稿
  • 投稿パフォーマンスの集計と運用改善
  • Claude Code を用いた教育コンテンツの配信

3. 第三者への提供

当方は、利用者から取得した情報を、以下の場合を除き第三者へ提供しません。

  • 利用者本人の同意がある場合
  • 法令に基づく開示請求があった場合
  • Meta Platforms / X への投稿リクエスト送信（API 利用に必要な範囲）

4. データの保管

アクセストークンは macOS Keychain にローカル保管され、外部送信は API 認証時のみ行われます。生成したコンテンツのテキスト・画像・動画はローカルマシンおよび当方所有の AWS S3 / CloudFront に保管されます。

5. データの保管期間

  • アクセストークン: トークン失効まで（60日 / 無期限）
  • 生成コンテンツ: 配信後12ヶ月、その後ローカルアーカイブへ移動
  • エンゲージメント集計データ: 24ヶ月

6. クッキー・トラッキング

本サイトはクッキーやトラッキング技術を使用しません。Meta Platforms / X 上でのトラッキングは各社のプライバシーポリシーに従います。

7. 利用者の権利

利用者は当方所有のSNSアカウントの所有者本人を指します。本人による以下の操作は随時可能です。

  • アクセストークンの取り消し（Meta / X 開発者ダッシュボードから操作）
  • 本サービスの停止（launchctl unload によるローカル停止）
  • 生成コンテンツの削除（ローカルファイルおよびSNS上の投稿の削除）

8. ポリシーの変更

本ポリシーの内容は予告なく変更されることがあります。変更後の内容は、本ページに掲載した時点で効力を生じます。

9. お問い合わせ

本ポリシーに関するお問い合わせは、X DM @claude_code_jp までお願いします。

10. 利用規約

本サービスは個人事業主（運営者: りょうせい）が自己所有のSNSアカウント運用を目的として開発・運用するものであり、第三者への提供を予定していません。本ソースコードを参考にする利用者は、自己のリスクにおいて利用するものとします。
